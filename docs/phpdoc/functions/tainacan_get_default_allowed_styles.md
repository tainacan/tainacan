# tainacan_get_default_allowed_styles


Adds CSS properties to the safe_style_css filter
These properties are needed for the media gallery component (e.g., .media-full-content)

***

* Full name: `tainacan_get_default_allowed_styles`
* Defined in: `classes/tainacan-utils.php`

## Parameters

| Parameter | Type      | Description                         |
|-----------|-----------|-------------------------------------|
| `$styles` | **array** | Array of allowed CSS property names |

## Return Value

**array**

Modified array with additional CSS properties
