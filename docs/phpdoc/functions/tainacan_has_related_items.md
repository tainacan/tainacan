# tainacan_has_related_items


Checks if the current item has or not related items

***

* Full name: `tainacan_has_related_items`
* Defined in: `classes/theme-helper/template-tags.php`

## Parameters

| Parameter  | Type                   | Description                                                            |
|------------|------------------------|------------------------------------------------------------------------|
| `$item_id` | **int\|string\|false** | (Optional) The item ID. Default is false (uses current item from loop) |

## Return Value

**bool**

True if item has related items, false otherwise
